# Week 02 - React Recipe Card

For this assignment, I converted my spaghetti carbonara recipe into a React application.

I separated the recipe into reusable components for the image, recipe information, ingredients, instructions, and card layout. The recipe content is stored separately in a data file and passed into the components using props.

I also styled the recipe card and added a user rating feature using React state. The rating lets the user add or remove up to five hearts.
