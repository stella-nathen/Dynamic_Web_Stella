# Week 03 – Component Library

This week we worked on reusable React components.

In class, I built:

- a reusable `Button` component with different variants and styles
- an `Accordion` component using `useState`
- conditional rendering with `&&` and ternaries
- icons with `react-icons`
- Tailwind styling with `classnames` and `tailwind-merge`

The main focus was understanding how to make components reusable and how to decide what should be handled with props versus state.
