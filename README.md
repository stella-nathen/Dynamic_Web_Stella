# Dynamic Web Applications

This repository contains my assignments and projects for DM-UY 3193 Dynamic Web Applications at NYU Tandon.

## Week 01

For Week 01, I created a spaghetti carbonara recipe page using HTML and CSS.

The assignment focused on basic page structure, semantic HTML, styling, and organizing content for the web.

## Week 02

For Week 02, I converted my carbonara recipe into a React application.

I separated the recipe into reusable components for the image, recipe information, ingredients, instructions, and card layout. I used props to pass recipe data between components and `.map()` to render the ingredient and instruction lists.

I also added custom styling and an interactive user rating using React state. The rating allows the user to add or remove up to five hearts.
